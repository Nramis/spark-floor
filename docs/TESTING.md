# Проверка на телефоне

## Установка

1. Откройте [последний тестовый релиз](https://github.com/Nramis/spark-floor/releases).
2. В разделе **Assets** скачайте `spark-floor-0.10-debug.apk` на телефон.
   Архивы **Source code** нужны разработчикам, для установки они не подходят.
3. Откройте APK и разрешите установку из выбранного браузера или файлового менеджера.
4. Запустите **Ориентир Пол** и разрешите камеру.

Эта версия подписана тем же локальным ключом, что и тестовый APK 0.7 из этого проекта.
Если Android сообщает о конфликте подписи с другой установленной сборкой,
удалите старую версию и установите эту заново. При удалении потеряются настройки.

## Быстрая проверка — около пяти минут

| Проверка | Ожидаемый результат |
| --- | --- |
| Запуск приложения | Модель загружается, кнопка снимка становится доступна |
| «Проверить на встроенном коридоре» | Появляется маска пола; метры для примера отключены |
| Анализ с выключенной трапецией | Есть текстовый комментарий о поле; отсутствие трапеции не мешает озвучке |
| Открытый видимый пол без осевой линии | При подходящих параметрах сообщается длина отрезка по центру и расстояние до начала |
| Стул или коробка у пола | Возможный предмет описывается слева, по центру или справа; распознавание может ошибаться |
| Разрыв пола без известного предмета | Разрыв описывается как неопределённость, без выдуманного названия предмета |
| Высота не задана | Есть описание сцены и объяснение, почему нет метров |
| Кнопка «Помощь» | Открывается список команд; удержание не требуется |
| Первое нажатие «Голосовая команда» | Запрос микрофона; после разрешения нужно нажать кнопку ещё раз |
| Команда «Помощь» | Список команд, микрофон после команды выключен |
| Команда «Статус» | Сообщение о модели, камере, высоте и готовности наклона |
| Команда «Высота» | Открывается ввод высоты объектива в сантиметрах |
| Команда «Снимок» | Съёмка, обработка, затем описание результата |
| Команда «Повтори» | Повтор последнего результата; во время обработки — просьба подождать |
| «Подробнее о снимке» / «Подробнее» | Полное описание того же снимка, без обновления его возраста |
| «Отчёт о проверке» / «Отчёт» | Редактируемый текст для копирования или передачи выбранному приложению |
| «Не делай снимок» | Сообщение о неизвестной команде, съёмка не начинается |
| Второе нажатие во время записи | Микрофон выключается, команда отменяется |
| «Остановить речь и микрофон» | Речь останавливается без включения микрофона |
| Уход на главный экран во время записи | Запись и речь прекращаются |
| Молчание после включения команды | Сессия завершается ошибкой службы или по тайм-ауту до 15 секунд |

Если русского голоса нет, установите локальный русский голос в настройках синтеза
речи Android и перезапустите приложение. Если нет распознавателя, можно пользоваться
кнопками. Системная служба распознавания может использовать сеть; перед её первым
использованием приложение предлагает отдельный выбор. Распознавание на устройстве,
когда оно доступно, используется без такого резервного перехода.

## Проверка метров и изгибов

Испытывайте на ровном полу, с неподвижным телефоном и сопровождающим.
Задайте измеренную высоту объектива. Проверьте прямой коридор и видимый изгиб.
Длина относится только к участку между концами розовой линии. Невидимое продолжение
не учитывается, безопасность прохода не определяется.

Сначала проверьте рулеткой точки 1,5 / 2 / 3 м от вертикальной проекции камеры.
После калибровки по одной точке проверяйте остальные, не подгоняя по ним настройку.

## Как сообщить результат

Создайте [issue](https://github.com/Nramis/spark-floor/issues/new) и укажите:

- Модель телефона, версию Android и версию приложения.
- Что нажали или какую команду произнесли.
- Что ожидали и что получилось; точный текст ошибки, если он есть.
- Для расстояний — высоту объектива и пары «рулетка → приложение».
- Скриншот, если он помогает понять проблему. Проверьте, что на нём нет личных данных.

## Автоматические тесты

На компьютере с Python 3 и JDK 17+:

```text
python tools/run_tests.py
```

Восемь наборов тестов также запускаются в GitHub Actions при изменении `main`,
в pull request и вручную через **Actions → Geometry and voice command tests → Run workflow**.
Они проверяют геометрию и словарь команд; для микрофона, TTS и камеры нужна проверка
на реальном телефоне.

Для версии 0.10 дополнительно пройдите [проверку с TalkBack](ACCESSIBILITY_TESTING.md).
